## 💫 Hi there 👋
I'm an electrical engineer turned software developer. After 18 years in the product certification industry, I pivoted to follow my passion for software and joined <a href="https://www.42barcelona.com/es/">42 Barcelona</a> in January 2023, completing the <a href="https://github.com/jesuserr/42cursus">common core curriculum</a> in July 2024.

Today I work as a **Software Developer** at <a href="https://www.onehub.energy">One Hub Energy</a>, a Barcelona-based company specialised in renewables, battery energy storage (BESS) and grid flexibility. In parallel, I keep sharpening my low-level skills through the <a href="https://github.com/jesuserr/42cursus_outer_core">outer core projects</a> of the 42 curriculum.

## ⚡ What I'm working on at One Hub Energy
- **Grid capacity data platform:** containerised pipeline that ingests, normalises and versions grid access-capacity data published by Spanish TSO/DSOs, stored as time series and exposed through an API and an interactive map.
  - Python ingestors and scrapers (ArcGIS REST, Excel, web sources), scheduled workers and change detection
  - PostgreSQL + TimescaleDB, FastAPI, React + Vite, AWS S3, Docker
- **OneDev platform (Odoo 19):** internal platform for renewable project development, including GIS layers served via GeoServer and a reproducible Docker dev environment shared by the team.
